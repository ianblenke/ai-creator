## Description

This part takes you from a bare Linux machine to your first render, with no graphics card, no voice server and, once the tools are built, no internet connection. The example's narration is silent on purpose: a placeholder with the right length, so you can see the pictures and the video come out before you record or clone your own voice.

What the video covers: what you need, getting the project and the Claude Code coding agent, the first prompt to give it, the list of private names that must never reach a screen, building the container, running the tests, and the offline render. It ends with what is missing from a silent render, why I keep the voice and your keys on your own machine (my judgement, not a test), and the prompt for starting your own series.

Only Linux on an Intel or AMD processor was tested here. Build and render times are from my own runs in early November of 2026 and will differ on your machine.

Code, docs and the example: https://github.com/ianblenke/ai-creator (this video matches the tag part-02)

How this was made
The narration is a cloned copy of my own voice, generated with Audio8-TTS-Realistic 0.6B from my own reference clip. It is not a recording of me reading; the model adds no watermark, so I am saying so here.
Voice model: Audio8-TTS-Realistic 0.6B by Edge0, Apache-2.0 license (read 2026-11-01): https://huggingface.co/Edge0/Audio8-TTS-Realistic-0.6b
Pictures were written by a cloud model and checked by me; I decide what each episode says. Posted as made; ask for a part in the comments.
