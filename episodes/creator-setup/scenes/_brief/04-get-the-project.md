Write `scenes/04-get-the-project.js` following docs/scene-contract.md, the series bible (scenes/_brief/_bible.md) and tools/stage/style.js.

## Narration (what is spoken)

With the machine ready, get the project. Clone the repository with git, and step into its folder. Next, install Claude Code, the coding agent this series uses. On Linux the installer is a single line that you paste into a terminal, and asking for its version tells you it worked. Then start it from inside the project folder, and it asks you to sign in the first time. It needs a paid Claude plan, a Console account, or access through a cloud provider.

## Visual intent

- A terminal drawn as a flat panel. Four short command lines type in as they are spoken, each with a small green tick: the clone with the repository address, the step into the folder, the one-line installer, the version check. Then the word 'claude' types and a sign-in card slides in. The three ways to sign in sit on the card, and the same words stay under it.
