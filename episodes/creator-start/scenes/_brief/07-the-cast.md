## Narration (what is spoken)

Catching it took a machine, and that is how this whole setup works. Three different jobs, each done by a different model. One speaks, in my voice, on my own graphics card. One listens, and compares what it hears to the script. A cloud model writes the pictures, and a cloud agent runs the pipeline and checks the work, so that someone checks the checkers.

## Visual intent

- Three flat jobs in a row, each with its own colour and a simple sign: a speaker (a waveform) running on a graphics card, a listener (an ear next to a script page and a small compare mark), and a cloud writer (a cloud with a code bracket). Above them a cloud agent runs the whole row, and a small loop arrow returns from the end to check the checkers.
