## Description

This is the map for a series that takes one pipeline apart: how a single person makes a finished, narrated explainer, one problem at a time. You plan first, the voice goes first, the pictures follow the audio, and checks catch what your ears miss. Each later part takes one problem, so start with the one you have.

What you bring: a computer with a decent graphics card and something you want to explain. The smallest card I have tested is a 24 GB consumer card; smaller cards are untested. Cloud models do the parts a home card cannot.

Code, docs and the example: https://github.com/ianblenke/ai-creator (this video matches the tag part-00)

How this was made
The narration is a cloned copy of my own voice, generated with Audio8-TTS-Realistic 0.6B from my own reference clip. It is not a recording of me reading; the model adds no watermark, so I am saying so here.
Voice model: Audio8-TTS-Realistic 0.6B by Edge0; Apache-2.0 license (read 2026-11-01), the model card does not describe its training data: https://huggingface.co/Edge0/Audio8-TTS-Realistic-0.6b
Pictures were written by a cloud model and checked by me; I decide what each episode says. Posted as made; ask for a part in the comments.
