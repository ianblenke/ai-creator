## Description

A script that reads well on a page can fall apart when it is only heard, because a listener cannot see the headings that tell a reader the subject has changed. This part covers writing for the ear: the bridge that says why the next topic follows, one story and a reason per scene, the critic that attacks a script's claims, and the flow review that reads the whole thing as a listener would. It ends on what neither reviewer can catch, which you still check yourself by reading the script aloud.

The flow review began when a viewer told me one of my own videos "just stops talking and changes the subject". I have paraphrased that comment, which was left on 2026-10-20.

Both reviewers read text and neither can hear, so they cannot tell whether a sentence sounds like you or whether a joke lands.
