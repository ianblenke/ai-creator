# Scene brief: 08-running-them

Write `scenes/08-running-them.js` following docs/scene-contract.md, the series bible (scenes/_brief/_bible.md) and tools/stage/style.js.

## Narration (what is spoken)

Both reviewers only work if they see what they should, the critic its facts, the flow review only the script. So you run each one in its own fresh folder, holding only its input files. The flow review gets no fact sheet, because a listener has none. To stop either one from changing anything, I run them in the Claude Code agent, an AI assistant that runs in a terminal, and I allow it only to read files. The critic goes first, because there is no point smoothing a sentence that turns out to be wrong. Then you fix what it found, run the flow review, and fix again. Fix every high and every medium, and run the flow review once more on the new script. You do all of this before any recording, because changing a sentence on the page costs nothing, and changing it later means recording it again.

## Visual intent

- A row of four boxes in order: critic, fix, flow review, fix. A small recording-mic icon sits dim after them behind a gate bar labelled before recording. A loop arrow returns from the last fix to the flow review.
