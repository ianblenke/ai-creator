## Things to know
- **Copyleft:** `libsndfile` (inside the soundfile wheel) is LGPL-2.1, and espeak-ng (inside the Kokoro image) is GPL-3.0-or-later.
  This repository only lists them; it does not redistribute them. If you publish a built image that contains them, their obligations
  apply to that image. `praat-parselmouth` (GPL-3.0-or-later) was removed on 2026-10-28: pitch and loudness now come from
  `tools/pitch.py` (numpy only); see `docs/pitch-replacement.md`.
- **NOT read:** NVIDIA's terms for the proprietary runtime packages that the Linux CUDA PyTorch wheels pull in (the `chatterbox` GPU
  image and the `gpu` image), the AudioSet data terms, bundled libraries inside the numpy/scipy/soundfile wheels, the licence of the
  Triton kernels the `gpu` image uses, and the base image of the `gpu` image.
- **Chatterbox:** its pip dependencies (about 100 packages, e.g. gradio, librosa, pre-commit) were NOT audited. Pinned versions are in
  `docker/chatterbox/requirements.txt`. Every output carries the Perth watermark (see NOTICE): this project never turns it off.
- **Kokoro:** "Apache-2.0" on the page is the code and weights. It does not tell you how every clip in its training data was licensed;
  the two CC BY sources ask for credit, so credit them in your description.
- **Voice use:** OmniVoice's own README prohibits unauthorized voice cloning, impersonation and fraud. This project clones only
  its author's voice. Disclosure of a cloned voice to viewers: see the README ("Disclose the cloned voice").
