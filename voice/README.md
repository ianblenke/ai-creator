# voice/

Put your OWN reference recording here: a clean 10 to 30 second clip of you speaking, 16-bit PCM mono WAV (`voice/ref.wav`).
How to record and convert it, a reading text, and a test: `docs/voice-reference.md`. Everything in this folder except this file and
`CONSENT.example.md` is gitignored and blocked by the repo check: never commit a voice sample or a transcript of one.

Only clone your own voice, or one you have written permission to clone. See `docs/voice-cloning-law.md` and `CONSENT.example.md`.
